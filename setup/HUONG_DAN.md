# Bộ cài VC Cost 0.8.3 (Windows)

File cài đặt được chia thành 5 phần (`.part00`–`.part04`) vì giới hạn dung lượng GitHub (100MB/file).

1. Tải cả thư mục `setup/` về cùng một chỗ (5 file part + `NOI_FILE_VA_CAI.bat`).
2. Chạy `NOI_FILE_VA_CAI.bat`: script nối các phần thành `VC-Cost-0.8.3-Setup.exe`, kiểm tra SHA256 rồi mở bộ cài.
3. Hoặc nếu bạn đã tải toàn bộ mã nguồn về máy, bạn có thể chạy trực tiếp file bộ cài đặt tại:
   `dist/VC-Cost-0.8.3-Setup.exe`
