# Bộ cài VC Cost 0.6.17 (Windows)

File cài đặt được chia thành 4 phần (`.part00`–`.part03`) vì giới hạn dung lượng GitHub.

1. Tải cả thư mục `setup/` về cùng một chỗ (4 file part + `NOI_FILE_VA_CAI.bat`).
2. Chạy `NOI_FILE_VA_CAI.bat`: script nối các phần thành `VC-Cost-0.6.17-Setup.exe`, kiểm tra SHA256 rồi mở bộ cài.
